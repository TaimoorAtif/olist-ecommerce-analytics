# Project Documentation

This folder contains the Excel Draft Board used throughout my Olist E-Commerce Analytics project.

The workbook records the project from initial data exploration through validation, staging, modelling, analysis, business recommendations and Power BI reporting.

It contains eight worksheets, including a cover page explaining the workbook and a guide to the remaining sheets.

The documentation includes working notes, data-quality findings, modelling decisions, analysis results, Power BI development steps and final QA checks.

The workbook is provided as a read-only reference copy for portfolio review.
