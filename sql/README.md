# SQL Scripts

This folder contains the PostgreSQL scripts I used for the Olist E-Commerce Analytics project.

- **olist-selected-queries.sql** — A shorter selection of SQL queries covering data validation, transformation, modelling checks and business analysis.
- **olist-working-script.sql** — My original SQL working file, including exploratory queries, data checks, staging, modelling and analysis.

The original working script records my development process and was not designed to run from beginning to end as a single automated setup script.

The selected queries mainly reference the populated `RAW`, `stage` and `analytics` schemas used during the project. They have not been independently tested against a fresh database.

The original dataset is the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.
