# Power BI Dashboard Screenshots

This folder contains screenshots of the completed six-page Power BI report developed for the Olist E-Commerce Analytics project.

The six main screenshots show the primary views of each report page, covering executive performance, customers and markets, products and sellers, delivery and satisfaction, payments and order economics, and executive recommendations.

The `alternates` folder contains additional screenshots demonstrating the report's bookmark-controlled views.

These are static images of the original Power BI report. They do not provide the interactive filtering, tooltips, navigation and bookmark functionality available in Power BI Desktop.
